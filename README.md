NEWSHUB-
A simple and responsive React.js web app that displays the latest news articles using the NewsAPI.
Built with Vite, Axios, and Tailwind CSS.

Features - 
1.Fetches real-time news from NewsAPI
2.Browse news by categories (Technology, Sports, Business, Health)
3.Search news by keyword
4.Responsive design using Tailwind CSS
5.Dynamic routing with React Router

Tech Stack-React (Vite),Tailwind CSS,JavaScript(ES6+),News API
